# Паспорт данных

Диагностическая версия от 2026-11-16 содержит 114 валидационных и 57 тестовых запросов. В валидации 50 исходных и 64 неполных запросов, в тесте — 25 исходных и 32 неполных. Пять исключённых запросов перечислены в [паспорте версии](dataset.json). Количество фото и карточек указано в [описании версии](dataset.json).

Сценарии формировались на основе попарных сравнений. В автоматических сериях для каждого пакета создавались два образа и две карточки с одинаковыми значениями основных фильтров и различимым визуальным признаком. Сценарии проходили предварительную проверку. По каждому запросу строился полный список товаров с соответствующими фильтрами, а подходящие карточки размечались вручную. Дополнительные запросы формировались снятием одного или нескольких необязательных фильтров, если это давало более широкий список. Связанные фото, товары и сценарии одного пакета относились к одной выборке. Общих файлов изображений между выборками нет.

В каждой выборке `people.json` связывает ID фотографий с файлами изображений. `catalog.json` содержит SKU и признаки товара, относительный путь к изображению и SHA-256. `scenarios.json` описывает запрос, фото, заданные фильтры, все допустимые SKU, соответствие номеров карточкам и разметку подходящих номеров. Часть изображений получена синтетически. При повторном эксперименте используются зафиксированные изображения из комплекта.

Gradio использует 59 карточек и 52 фотографии образов из `data/validation/`. Тестовый каталог и фото используются при воспроизведении оценки.

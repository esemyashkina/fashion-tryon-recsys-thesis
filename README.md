# Виртуальная примерка и подбор одежды

Приложение Gradio подбирает одежду по фотографии образа и заданным фильтрам. FashionCLIP ранжирует товары, GPT‑6.1 Terra выбирает вещь из первых шести карточек и объясняет выбор. FASHN VTON 1.5 создаёт изображение примерки выбранной или загруженной вещи. В интерфейсе доступны 59 карточек и 52 фотографии образов из валидационного каталога.

## Быстрый запуск на Vast.ai

Подготовьте инстанс Linux с шаблоном **PyTorch**, Python **3.12**, рабочими CUDA, PyTorch и torchvision, диском от **100 ГБ** и GPU с **12 ГБ VRAM или больше**. Для этого профиля предпочтительны NVIDIA Ampere или новее с поддержкой BF16. Скопируйте папку репозитория на сервер и откройте терминал в ней. Скрипт сохраняет версии PyTorch и torchvision из шаблона, устанавливает зависимости, загружает веса и проверяет установку.

```bash
bash scripts/setup_vast.sh
.venv/bin/python -m src.tryon --case FC021
.venv/bin/python -m src.app
```

Проверочная примерка записывается в `runs/tryon.png`. Для просмотра Gradio пробросьте порт через SSH, используя параметры подключения из Vast, и откройте `http://127.0.0.1:7860` на своём компьютере.

```bash
ssh -N -L 7860:127.0.0.1:7860 -p SSH_PORT SSH_USER@SSH_HOST
```

API-ключ нужен для подбора по фотографии. Создайте `.env` из `.env.example`, задайте `OPENAI_API_KEY` с доступом к `gpt-6.1-terra`. Запросы на подбор отправляют фото образа и карточек в OpenAI. Примерка выполняется на сервере с GPU и доступна без API-ключа. На первом запуске примерки могут дополнительно загрузиться веса сегментации. При первом обращении создаётся база SQLite для фильтрации каталога. При первом подборе FashionCLIP вычисляет векторы изображений и сохраняет их в индексе USearch в `runs/indexes/`. После перезапуска индекс загружается с диска. При изменении изображений создаётся новый индекс. Ранжирование вычисляет точное косинусное сходство по векторам товаров, прошедших фильтрацию.

Во вкладке **Подбор из каталога** выберите фото и категорию. Тип, цвет и стиль можно оставить пустыми. Нажмите **Подобрать вещь**, затем **Примерить выбранную вещь**. Во вкладке **Примерка выбранной вещи** доступен выбор каталожной карточки или загрузка своего изображения. Для загруженной вещи укажите тип фото. `flat-lay` — вещь отдельно, `model` — вещь на человеке. По умолчанию выполняется 10 шагов примерки.

Для своей пары изображений доступна команда:

```bash
.venv/bin/python -m src.tryon --person person.png --garment garment.png --category tops --photo-type flat-lay --output runs/custom.png
```

## Воспроизведение оценки

Пересчёт опубликованных таблиц требует только Python 3.12. Он использует размеченные запросы и сохранённые ранжирования и решения Terra. Тест проверяет контрольные суммы изображений, отсутствие общих изображений между выборками, состав списков кандидатов и итоговые метрики.

```bash
python3.12 -m unittest discover -s tests
python3.12 -m src.evaluate --out runs/metrics.json
```

Контрольный результат доступен в [reports/metrics.json](reports/metrics.json). В валидации 114 запросов, в тесте 57. Для проверки подбора размера списка сравниваются K = 2, 4 и 6, для финального выбора — три промпта. Полный прототип с K = 6 и промптом «Готовые образы» получил **106/114 (93,0%)** на сокращённой диагностической валидации и **52/57 (91,2%)** на тесте. Пять запросов валидации исключены по повторяющимся ошибкам двух предыдущих прогонов. Идентификаторы и правила отбора указаны в [паспорте данных](data/dataset.json).

Для повторного вычисления ранжирования на CPU установите версии зависимостей из `requirements-inference.txt`. На Vast используйте уже установленное окружение. FashionCLIP загружается по закреплённой ревизии. Для полного прогона с новыми поисковыми фразами и решениями Terra нужен доступ к API.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-inference.txt
.venv/bin/python -m src.predict validation
.venv/bin/python -m src.predict test
```

Для нового сравнения K и промптов и повторной оценки теста:

```bash
.venv/bin/python -m src.predict validation --live --sweep-k
.venv/bin/python -m src.predict test --live
.venv/bin/python -m src.evaluate --predictions runs --out runs/live_metrics.json
```

Новые ответы Terra могут отличаться от сохранённых. Платный прогон записывает отдельные файлы в `runs/`. Для повторения того же запуска перенесите ранее созданный файл с соответствующим именем.

## Состав и права

- [src/](src/) — Gradio, SQLite-каталог, рекомендация, виртуальная примерка и оценка.
- [scripts/setup_vast.sh](scripts/setup_vast.sh) — установка на инстансе Vast.
- [data/](data/README.md) — изображения, метаданные и разметка. Тестовые данные используются в оценке. Интерфейс загружает каталог и примеры из `data/validation/`.
- [prompts/](prompts/) — инструкции для генерации запроса и финального выбора.
- [reports/](reports/) — раздел ВКР, эталонные предсказания и результаты экспериментов.
- [tests/](tests/) — проверки данных, метрик и интерфейса.

Условия использования кода и изображений приведены в [LICENSE](LICENSE). Условия внешних моделей приведены в репозитории FASHN VTON 1.5 и карточке FashionCLIP. Веса моделей загружаются при установке. При публикации вопросы по проекту можно направлять через Issues репозитория.
